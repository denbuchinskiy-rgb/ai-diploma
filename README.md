Описание
Это учебный проект с базой данных SQLite.
Проект создан после блока занятий по базам данных, SQL и sqlite3.
Что умеет проект
•	создаёт SQLite-базу данных;
•	создаёт таблицу учебных проектов студентов;
•	добавляет демонстрационные данные;
•	показывает все проекты;
•	фильтрует проекты по статусу;
•	считает средний score;
•	строит отчёт по статусам;
•	показывает топ-3 проекта.

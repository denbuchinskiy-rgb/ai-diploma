# Block 4 Core Project

## Назначение

Итоговый проект блока 4: собрать функции из занятий 1-11 в один проект VS Code.

## Используются только занятия 1-11
1. Векторы, матрицы, dot, norm, cosine, matvec
2. Векторы 2D: длина, сложение, умножение на число, dot, рисунок

## Запуск

```bash
python main.py
pytest
```

## Что должно быть на защите

- проект открывается в VS Code;
- есть папка src с функциями;
- есть папка tests с автопроверками;
- `python main.py` выполняется без ошибок;
- `pytest` проходит без ошибок;
- проект загружен на GitHub;
- студент может объяснить, из какого занятия взята каждая группа функций.
